# Fotos de modelos — paths esperados por el blog

Formato sugerido: JPG, **ratio 16:10 horizontal** (ej. 1280x800), fondo limpio o foto del modelo en estudio. Se renderea en card responsive con `object-fit: cover`, así que la moto debe estar centrada.

Si un archivo no existe, el componente muestra placeholder "Foto próximamente" + emoji 🏍️ automático. Subir el archivo al path correcto y `pm2 restart motopatio` lo activa (no requiere rebuild de Next).
